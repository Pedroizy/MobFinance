# 📱 MobFinance — App de Controle Financeiro

![Badge Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)
![Badge Expo](https://img.shields.io/badge/expo-51.0.0-blue)
![Badge ReactNative](https://img.shields.io/badge/react--native-0.76-purple)
![Badge License](https://img.shields.io/badge/licença-MIT-green)

O **MobFinance** é um aplicativo mobile criado com **React Native + Expo** para ajudar você a organizar suas finanças de forma simples, rápida e eficiente.

Com ele, você consegue visualizar seu saldo, acompanhar suas entradas e saídas, acessar ações rápidas e muito mais — tudo em uma interface moderna e amigável.

---

# 🚀 Funcionalidades

- Visualização de saldo atual  
- Listagem de movimentações (entradas e saídas)  
- Ações rápidas (transferir, pagar, receber...)  
- Interface leve e moderna  
- Performance utilizando componentes otimizados  
- Estrutura pronta para integração com API real futuramente

# ▶️ Como Rodar o Projeto

### **1. Instalar dependências**
```bash
yarn install
```

### **2. Iniciar o projeto**
```bash
yarn start
```

### **3. Escolher onde rodar**
- **a** → Android  
- **i** → iOS (apenas macOS)  
- **w** → Web  
- Scanner do QR Code via aplicativo **Expo Go**
